Transition.js

Slides in HTML and CSS, written the way you write beamer. One JavaScript file, no dependency.

Examples

  • La méthode de Newton — a short maths talk; its beamer twin is newton.tex (PDF)
  • Beamer theme — part titles, persistent headline, blocks
  • Minimal — the least you need
  • Feature tour — fragments, effects, overview, MathJax, graphs, iframes
  • Fade mode

Keys: Space, Enter, arrows, PageUp/PageDown, Home/End; Escape for the overview.
